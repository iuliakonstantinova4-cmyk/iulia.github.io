Урок 31

Как правильно выключать компьютер

Просто закрыть крышку ноутбука — это не выключить. Компьютер продолжает работать в режиме сна, тратит заряд и не завершает обновления.

Windows — выключение

  1. Нажми кнопку «Пуск» (флажок Windows слева внизу)
  2. Нажми на иконку питания
  3. Выбери «Завершение работы»
  4. Подожди, пока экран погаснет полностью

Mac — выключение

  1. Нажми на яблоко 🍎 в левом верхнем углу
  2. Выбери «Выключить…»
  3. Подтверди «Выключить» в диалоге
  4. Подожди, пока экран погаснет полностью

Урок 32

Как сделать скриншот

Скриншот — это фотография экрана. Незаменимая вещь: сохранить переписку, показать ошибку, поделиться информацией.

На телефоне

iPhone с Face ID

Одновременно нажми кнопку сбоку + кнопку громкости вверх. Экран мигнёт — скриншот в галерее.

iPhone с кнопкой Home

Одновременно нажми кнопку сбоку + кнопку Home (круглая снизу). Экран мигнёт.

Android (большинство)

Одновременно нажми кнопку питания + кнопку уменьшения громкости. Держи 1–2 секунды.

Android — жест

На многих Samsung и Xiaomi: проведи ребром ладони по экрану справа налево.

На компьютере

Windows

  • Весь экран: клавиша Print Screen (PrtScn)
  • Активное окно: Alt + PrtScn
  • Выделить область: Win + Shift + S
  • Сохранить сразу в файл: Win + PrtScn → папка «Снимки экрана»

Mac

  • Весь экран: Cmd + Shift + 3
  • Выделить область: Cmd + Shift + 4
  • Активное окно: Cmd + Shift + 4, затем Пробел + клик
  • В буфер: добавь Control к любой комбинации
Самый простой способ на WindowsWin + Shift + S — появится тёмный экран с прицелом. Выдели нужную область мышью. Скриншот скопируется в буфер — вставь его в чат или письмо через Ctrl + V.

Как подключить телефон к компьютеру и передать файлы

Нужно перенести фото на компьютер или скачать документ на телефон? Кабель — самый надёжный способ.

iPhone → Mac

  • 1Подключи iPhone к Mac кабелем Lightning или USB-C.
  • 2На iPhone появится запрос «Доверять этому компьютеру?» — нажми «Доверять» и введи код разблокировки.
  • 3На Mac откроется приложение «Фото» — нажми «Импортировать все новые объекты» или выбери нужные фото вручную.
  • 4Для файлов: используй Finder → слева найди свой iPhone → папка «Файлы».

iPhone → Windows

  • 1Подключи iPhone кабелем, нажми «Доверять» на телефоне.
  • 2Открой «Этот компьютер» (Win + E).
  • 3Найди свой iPhone в списке устройств → Internal Storage → DCIM → здесь все фото.
  • 4Скопируй нужные фото: правая кнопка мыши → «Копировать» → вставь в нужную папку.

Android → Windows или Mac

  • 1Подключи кабель USB. На телефоне появится уведомление о подключении — нажми на него.
  • 2Выбери «Передача файлов» (File Transfer / MTP) — не «Зарядка».
  • 3На компьютере открой «Этот компьютер» → зайди в папку DCIM для фото.
  • 4Перетащи нужные файлы на компьютер или скопируй через правую кнопку мыши.
Альтернатива без кабеляЗагрузи файлы в Google Диск или iCloud с телефона — и скачай на компьютере через браузер. Работает через Wi-Fi, кабель не нужен.
Урок 34

Как безопасно «вытащить» флешку

Флешку нельзя просто выдернуть из компьютера — это может повредить файлы. Нужно сначала «отключить» её правильно. Это занимает 5 секунд.

На Windows

  1. Найди иконку флешки в правом нижнем углу экрана
  2. Кликни на неё правой кнопкой мыши
  3. Выбери «Извлечь [название флешки]»
  4. Появится надпись «Теперь устройство можно безопасно извлечь»
  5. Только теперь вытаскивай флешку

На Mac

  1. Найди флешку на рабочем столе или в Finder
  2. Нажми на иконку ⏏ рядом с названием флешки в Finder
  3. Или перетащи иконку флешки в Корзину (она превратится в ⏏)
  4. Иконка исчезнет — теперь можно вытаскивать
Что будет если выдернуть без извлеченияНасколько серьёзно
Файл, который копировался, повредитсяСерьёзно — файл может не открыться
Флешка может «слететь» и потребовать форматированияСерьёзно — все данные удалятся
Если ничего не копировалось в момент извлеченияЧаще всего ничего не случится, но риск есть
Запомни как правилоФлешка — как посуда в посудомойке: сначала дождись конца цикла, потом вынимай. Не раньше.
Урок 35

Как обновить систему и зачем это нужно

Обновления системы — это не просто новые иконки. Это заплатки безопасности, исправление ошибок и улучшение скорости.

Защита от вирусов

Хакеры находят дыры в старых версиях. Обновления их закрывают раньше, чем ими успевают воспользоваться.

Стабильность работы

Зависания, вылеты приложений, глюки — всё это часто исправляется в очередном обновлении.

Совместимость

Новые приложения рассчитаны на актуальные версии системы. Старая система = приложения могут не работать.

Новые функции

Улучшенная камера, новые эмодзи, быстрый поиск — всё это приходит с обновлениями.

Как обновить систему на телефоне

  • 1iPhone: Настройки → Основные → Обновление ПО. Телефон должен быть заряжен хотя бы на 50% и подключён к Wi-Fi.
  • 2Android: Настройки → Система → Обновление системы → «Проверить наличие обновлений».
  • 3Лучше обновлять вечером — телефон перезагрузится и может быть недоступен 10–20 минут.

Как обновить систему на компьютере

  • 1Windows: Пуск → Настройки → Обновление и безопасность → Windows Update → «Проверить наличие обновлений».
  • 2Mac: Яблоко 🍎 → Системные настройки → Основные → Обновление ПО.
  • 3Перед большим обновлением компьютера — сохрани важные файлы на флешку или в облако. На всякий случай.
Если компьютер давно не обновлялсяНе пугайся, если обновлений накопилось много — это нормально. Просто запусти проверку, подключись к Wi-Fi, оставь компьютер включённым и уйди заниматься своими делами. Он всё сделает сам.
